## 当前职责边界

`ExhibitEntry → ZoneExhibitShowcase → ZoneExhibitStand → onSelect(entry) → 既有 ZoneViewer / ExhibitViewer`

- `ZoneViewer`：展区环境、进入动画、来源展区与相机状态、既有展品打开/返回逻辑。
- `ZoneExhibitShowcase`：当前展区的展示集合、单一 RaycastManager、悬停和点击派发、替换与销毁。
- `ZoneExhibitStand`：一个轻量展台、代表性预览、标牌、热点和自有资源。
- `ExhibitViewer`：正式设备模型、旋转缩放、部件交互与深度展示。展示组件不得实例化或复制它。

未恢复左侧目录菜单。当前只有水环境展区已开放独立空间；其他四区的完整空间仍待后续阶段。

## 数据配置

`src/zones/data/zoneExhibits.ts` 新增可选 `showcaseKind`：
`mvr` / `membrane` / `monitoring` / `generic`。
未配置或运行时未知类型使用通用占位形态。不能再以数组索引决定模型类型。
`previewPosition` 指定展位坐标，`previewLabel` 指定空间标牌，`status` 决定可用状态。
MVR 的 `viewerId` 必须继续引用 `mvrWastewaterTreatmentDefinition.id`，不能写成未注册的 `mvr`。

添加预留展项时，配置唯一 id、所属展区、名称、展示类型与坐标，使用 `status: 'coming'`、`viewerId: null`。
添加正式展品仍需先实现并注册其模型/元数据，再引用真实注册 ID；仅添加配置不会自动生成完整工艺与拆解模型。

## 生命周期约束

返回展区复用原场景、展示对象和热点，不调用 setEntries 或重播进入动画。
从主厅重新进入展区时可以替换展示集合；旧集合的几何体、材质、标签纹理必须各释放一次。
集合只负责自己的资源，不得遍历释放全局/冻结模型资源。
切换、暂停、隐藏期间不能点击后台热点；不接收已被替换的旧热点。
